### [2026/11/28 7:47] [v1.0.1] v1.0.1: 図表の視認性と論点整理の分業機能を向上させました

・図解やチャート内の文字が潰れて見えにくかった現象を解消し、あらゆるテーマでもくっきりと読みやすい美しい表示に改善しました。
・思考キャンバスの初期テンプレートを「見える化・判断ナビゲーション型」に刷新し、議論の論点整理やロードマップ作成をよりスムーズに行えるようになりました。
・判断材料や比較表を初回から自動でスムーズに生成するパイプラインを強化し、ユーザーの待ち時間を減らして迷いのない意思決定をサポートします。

### [2026/11/23 14:34] [v1.0.0] v1.0.0: AIとの高度な壁打ちや思考整理を快適に行える「Studio Board」を初公開しました！

・AIとのスムーズな対話機能に加え、アイデアやノートを視覚的に整理できる専用キャンバスを搭載し、閃きを逃さず記録できるようになりました。
・思考の深さやアイデアの広がり方に合わせて「3段階の思考スタンス」を自由に切り替え、AIの回答トーンを自在にコントロールできるようになりました。
・作成したデータやチャット履歴は一括で安全に保存・復元できるため、長時間のブレインストーミングやプロジェクトの継続も安心です。
・サイバーエレガンスを基調とした洗練されたダークテーマと、視認性を徹底追求した美しく揺るぎない操作パネルにより、長時間の作業でも疲れにくい快適な体験を提供します。
